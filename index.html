Offline Network Active

🚨 Emergency SOS

Send an emergency message through nearby devices.


🔄 Message Routing

If the destination device is not directly reachable, the emergency message can travel through nearby devices.

Device A → Device B → Device C → Device D

💡 How It Works

1. Devices discover nearby devices.

2. User sends an emergency message.

3. The message is forwarded through nearby devices.

4. The emergency message reaches the destination.
